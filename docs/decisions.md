### Shared-calendar choice

Use one dedicated **RTV Discovery Calls** calendar with an assigned host on every call. The provisional Gmail can own it initially; move ownership into RTV’s business Google Workspace when its account administration is ready. Each person keeps their own login, and receives calendar access appropriate to their job. Do not share the Gmail password.

Availability must include the assigned host’s calendar as well as the shared calendar. Merely adding a co-host does not make Google check that person’s availability. Appointment-schedule features vary by Google subscription, so the final connection must be checked against the actual account. The application currently saves requests and can record confirmed Google event links. The Google API adapter can create 30-minute events and invites after credentials and calendar sharing are connected; it has not been tested against RTV’s live calendar.

Official references: https://support.google.com/calendar/answer/10729749?hl=en and https://developers.google.com/workspace/calendar/api/v3/reference/freebusy/query.
